KeepLocal Architecture & Roadmap

A privacy-first, offline Android note-taking application powered by on-device EmbeddingGemma, signature-protected inter-app model sharing, and local NAS network backups.

Core Platform Targets

  • Target SDK: Android 14+ (minSdk 26)
  • UI Framework: Jetpack Compose + Material 3 (Dark Theme default)
  • Database: Android Room with SQLite FTS5 extension
  • Runtime: Google LiteRT (com.google.ai.edge.litert)

Zero-Cloud Sandbox Invariants

  • No external cloud telemetry, accounts, or analytics services.
  • Model file downloaded on-demand once, verified via SHA-256 hash, then retained locally.
  • Backup operations communicate exclusively with local SMB/Samba network shares.

2. Persistence & Vector Index Schema

EmbeddingGemma produces 768-dimensional embeddings by default. Using Matryoshka Representation Learning (MRL), output tensors are sliced down to 128 dimensions, packed into 512-byte binary blobs, and persisted in Room.

// 1. Core Note Record
@Entity(tableName = "notes")
data class NoteEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val title: String,
    val content: String,
    val noteType: NoteType,             // TEXT, CHECKLIST, PROJECT_TASK, EVENT
    val isPinned: Boolean = false,
    val isArchived: Boolean = false,
    val reminderEpochMs: Long? = null,
    val updatedAt: Long = System.currentTimeMillis()
)

// 2. Vector Store (128-dim FP32 = 512 bytes per record)
@Entity(
    tableName = "note_embeddings",
    foreignKeys = [
        ForeignKey(
            entity = NoteEntity::class,
            parentColumns = ["id"],
            childColumns = ["noteId"],
            onDelete = ForeignKey.CASCADE
        )
    ],
    indices = [Index(value = ["noteId"], unique = true)]
)
data class NoteEmbeddingEntity(
    @PrimaryKey val noteId: Long,
    @ColumnInfo(typeAffinity = ColumnInfo.BLOB) val vector: ByteArray,
    val dimensions: Int = 128,
    val updatedAt: Long = System.currentTimeMillis()
)

// 3. FTS5 Virtual Table for Exact Keywords & Symbols
@Fts4(contentEntity = NoteEntity::class)
@Entity(tableName = "notes_fts")
data class NoteFtsEntity(
    val title: String,
    val content: String
)

3. Vector Pipeline & Model Sharing Specifications

Asymmetric Task Framing

To avoid representation drift between questions and indexed notes, all inputs are formatted with prompt task prefixes before inference:

// Indexing Notes:
"task: search document | text: $title. $content"

// Querying Notes:
"task: search query | query: $userQuery"

MRL Slicing: Truncate LiteRT output array to rawOutput.copyOfRange(0, 128) and normalize with Euclidean L2 norm.

Signature FileProvider Contract

Exposes weights to companion apps signed by the same keystore without duplicating the ~180MB file:

<permission
    android:name="com.example.keeplocal.READ_MODEL"
    android:protectionLevel="signature" />

<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="com.example.keeplocal.modelprovider"
    android:exported="true"
    android:readPermission="com.example.keeplocal.READ_MODEL">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>

4. Local NAS Backup Integration (SMB 2/3)

Protocol & Dependencies

  • Client Engine: com.hierynomus:smbj:0.13.0
  • Credential Storage: Android EncryptedSharedPreferences
  • Execution: WorkManager (Wi-Fi connected + device charging triggers)

Archive Payload Composition

  • manifest.json: Schema metadata, device ID, timestamp, SHA-256
  • notes.json: Complete export of NoteEntity table
  • attachments/: Embedded photos and voice recordings
  • Note: Excludes vector blobs to keep backups tiny; vectors are recomputed automatically upon restore.

5. Implementation Roadmap for Google Jules

Phase 1

Core Database, FTS5 & Model Provider Setup

  • Initialize Android project targeting SDK 34 with Jetpack Compose and Room SQLite.
  • Implement NoteEntity, NoteEmbeddingEntity, and NoteFtsEntity schemas with corresponding DAOs.
  • Configure FileProvider in AndroidManifest.xml secured by signature protection level.
  • Build ModelManager with initial download, SHA-256 integrity verification, and atomic file commit into files/models/.
Phase 2

LiteRT Inference Pipeline & Vector Search

  • Integrate com.google.ai.edge.litert runtime dependencies.
  • Build EmbeddingRepository to execute inference from internal file storage or external FileDescriptor.
  • Implement MRL 128-dimension truncation, L2 vector normalization, and byte-packing utilities.
  • Configure a debounced WorkManager background worker to auto-embed new and modified notes.
  • Implement Reciprocal Rank Fusion (RRF) combining Room FTS5 text matches with in-memory vector dot product rankings.
Phase 3

Google Keep-Style UI & Smart Features

  • Implement staggered 2-column grid and single-column list views with pinned notes support in Jetpack Compose.
  • Build dynamic note cards supporting markdown text, interactive checklists, and labels.
  • Implement real-time debounced search bar with mode toggle: Hybrid (RRF), Semantic Only, and Exact Keyword.
  • Add a bottom "Related Context" drawer on the note editor that pulls top-3 semantic matches based on vector distance.
  • Build the ModelSettingsScreen displaying download progress, local disk usage, and SHA-256 status.
Phase 4

SMB NAS Backup & Restore Engine

  • Add smbj dependency and construct SmbBackupManager for LAN SMB share uploads.
  • Store NAS host IP, share name, username, and password in EncryptedSharedPreferences.
  • Build BackupArchiver to package notes and media into a compressed .tar.gz archive (excluding embedding blobs).
  • Implement NasBackupWorker with UNMETERED network and CHARGING constraints for automated overnight sync.
  • Create a "Restore from NAS" dialog to download and unpack archives, triggering an automatic background re-embedding pass.
